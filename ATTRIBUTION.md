# Icons

The phone app's interface icons come from **[game-icons.net](https://game-icons.net)**,
used under **[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)**. They are
redrawn as Android vector drawables in `android/app/src/main/res/drawable/ic_*.xml`;
each file names where it came from.

| Icon | Used for | Author |
|------|----------|--------|
| microphone | the call's microphone (the muted one is the same artwork, struck through) | Delapouite |
| video-camera | the call's camera | Delapouite |
| share | presenting your screen | Delapouite |
| cycle | flipping the camera | Lorc |
| cog | settings | Lorc |
| speaker | voice channels | Delapouite |
| chat-bubble | text channels | Delapouite |
| paper-clip | attachments | Delapouite |
| linked-rings | invites | Lorc |
| three-friends | members | Delapouite |
| exit-door, trash-can, pencil, cloud-download | leaving, deleting, editing, downloading | Delapouite |

The **send** arrow and the red **leave call** handset were drawn for take-back by
Etheri. The **plus** beside each heading is drawn here too — game-icons' plus
sits inside a ring and reads too thin on its own.
